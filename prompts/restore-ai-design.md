# Restore AI DESIGN LANE

Improve one launch-critical Restore AI customer journey while preserving media privacy/payment/cost controls.

## Visual identity
Human, archival, trustworthy restoration studio — not an AI demo.
- Let the customer's photo dominate.
- Neutral warm surfaces, restrained contrast, minimal decoration.
- Before/after comparison should be the signature interaction when a real result exists.
- Use subtle archival/editorial cues without fake vintage clutter.
- Avoid robot imagery, magic sparkles and generic AI gradients.

## Priority journey
1. Upload + supported-format/privacy explanation.
2. Order/package selection.
3. Processing/progress status.
4. Result before/after + download.
5. Failure/retry/recovery/refund states.
6. Mobile upload and result handling.

## Required UX
- Explain retention/deletion and privacy near upload, in concise language.
- Processing must never look frozen: clear state, next expectation, retry/help path.
- Payment/provider state and restoration state must be visually distinct.
- Never show fake before/after examples as if they were the user's result.
- Keep pricing and provider-cost complexity out of the primary customer flow unless decision-relevant.

Use the shared 2026 design standard. Finish with npm run check passing.
