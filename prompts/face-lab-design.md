# FACE LAB DESIGN LANE

Improve one end-to-end FACE LAB journey without adding speculative analysis modules.

## Visual identity
Contemporary beauty-tech editorial: clean, photographic, calm and credible.
- Base: warm white / soft neutral / ink black.
- Accent: one restrained skin/rose/metallic-neutral family only if the existing palette supports it.
- The uploaded photo/result is the hero, not decorative gradients.
- Avoid medical-clinic sterility and avoid playful selfie-filter/gamified beauty scoring.
- Use elegant data visualization only for real values.

## Priority journey
1. Photo upload and privacy reassurance.
2. Local preflight / face-count / image-quality feedback.
3. Analysis progress state.
4. Result hierarchy: best photo, angle, presentation, style guidance.
5. Upgrade/paid path when implemented.
6. Share/save and mobile 360/390/430.

## Required UX
- Make privacy and "what happens to my photo" understandable near upload.
- Use comparison layouts for multiple photos instead of long repetitive cards.
- Keep confidence/limitations visible but compact.
- Do not imply objective beauty, health, personality or sensitive-trait assessment.
- Design error/retry states as carefully as success states.

Use the shared 2026 design standard. Finish with typecheck/build/tests passing.
