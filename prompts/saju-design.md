# Daangn Saju / KR DESIGN LANE

Improve the Korea sales surface of Fortune Atlas without forking the underlying Saju engine.

## Visual identity
Premium Korean editorial interpretation service.
- Warm ivory + ink/charcoal + restrained gold/brass.
- Clean modern layout with subtle traditional cues; no fortune-teller poster aesthetic.
- No large purple mid-page banner.
- Avoid repeated vertical money/work/love cards when the same information can be structured more clearly.
- Use strong Korean typography hierarchy and short consumer copy.

## Priority journey
1. Birth input form: fast, clear, thumb-friendly.
2. Free result: primary interpretation first, technical evidence secondary.
3. Locked paid preview: obvious but not noisy.
4. Product selection: price, depth and differences at a glance.
5. PayApp checkout/return/recovery messaging.
6. Paid result/PDF/re-entry controls on mobile.

## Required UX
- Name, gender, date/time fields feel native and simple.
- Primary CTA remains reachable but never covers content.
- Payment state must look trustworthy and explicit: pending / verified / failed / retry.
- Do not use fake reviews, fake accuracy numbers or deceptive urgency.
- Remove redundant instructional prose and "how to read this" filler where the UI can explain itself.

Use the shared 2026 design standard. Finish with the release gate/build passing.
