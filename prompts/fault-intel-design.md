# Fault Intelligence DESIGN LANE

Improve one search/diagnostic journey without adding unverified fault content.

## Visual identity
Professional technical reference tool — fast, dense where useful, never cyberpunk.
- Search-first layout.
- Neutral light/dark technical palette with strong semantic status colors.
- Use monospace selectively for codes/SPN/FMI identifiers, not for body copy.
- Compact structured tables/rows are preferable to endless cards.
- No neon dashboards, radar graphics or fake telemetry.

## Priority journey
1. Search home / code entry.
2. Search result list.
3. Fault detail: meaning, applicability, severity/context, causes, checks, verified sources.
4. Related-code/internal navigation.
5. Mobile dense-content readability.
6. Disabled/ad-ready layout that does not damage the reference experience.

## Required UX
- Make verified/unverified/noindex/source state legible.
- Distinguish universal code meaning from OEM/model-specific applicability.
- Put the most actionable diagnostic information above secondary SEO text.
- Dense information must still scan well at 360/390/430.
- Accessibility and keyboard search are first-class.
- Never beautify by hiding source provenance or uncertainty.

Use the shared 2026 design standard. Finish with npm run check passing.
