# TradePilot AutoDev
Continue the private beta as a practical, low-risk trade sourcing and sales-assistance product.
Priority:
1. Turn the bootstrap into a coherent testable FastAPI application using the existing dependencies.
2. Focus on product/supplier/buyer data models, landed-cost and margin checks, evidence/provenance and exportable opportunity records.
3. Protect against negative-margin recommendations; include freight, duties, fees and uncertainty where inputs exist.
4. Never fabricate suppliers, buyers, RFQs, prices, orders or revenue.
5. No live outreach, purchases, payments, paid APIs or production deployment.
Keep the batch small, reviewable and covered by deterministic tests where source exists.
