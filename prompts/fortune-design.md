# Fortune Atlas DESIGN LANE

Redesign one coherent Fortune Atlas journey while preserving all Saju/payment/report logic.

## Visual identity
Premium East-Asian editorial, not occult kitsch and not generic SaaS.
- Base: near-black ink / deep charcoal / warm ivory.
- Accent: restrained antique-gold/brass; use it for hierarchy, not everywhere.
- Avoid purple gradient banners and fantasy-game effects.
- Combine modern editorial typography with subtle traditional texture/geometry only where it adds identity.
- The result itself should feel like a premium personal report, not a dashboard full of widgets.

## Priority screens
1. Birth input + first-screen value proposition.
2. Free result hierarchy and immediate paid-preview transition.
3. Product choice / Standard-Premium-Signature comparison.
4. Checkout/return/recovery state.
5. Paid web report + PDF controls + re-entry.
6. Mobile 360/390/430.

## Conversion rules
- Above the fold: one clear promise, input/action, minimal supporting trust.
- Free result must reveal enough real value before the paid choice.
- Product tiers must be understandable without reading paragraphs.
- Avoid manipulative countdowns, fake scarcity or unverifiable accuracy claims.
- Trust/FAQ/refund/privacy should support the purchase decision without dominating the page.
- Keep KR and global market copy/price/provider separable.

Use the shared 2026 design standard. Finish with the configured validation passing.
